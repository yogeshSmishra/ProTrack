# ProTrack - C# Practice Project

This is a hands-on project I am building to practice **C#** and **.NET fundamentals** during my internship at **Coditas**. 

The goal is to move away from just watching lectures and actually apply concepts like OOP, Logic separation, and Data modeling in a real application.

## 🛠️ Current Status
- **[Models](./ProTrack/Models/TaskItem.cs)**: Defines the data structure for tasks.
- **[Logic](./ProTrack/Logic/TaskLogic.cs)**: Handles the "brains" of the app (adding and viewing tasks).
- **[Program](./ProTrack/Program.cs)**: The console interface where I interact with the code.

## 📚 Learning Focus
- Object-Oriented Programming (OOP)
- C# Syntax & Enums
- Layered code structure (Separation of Concerns)
